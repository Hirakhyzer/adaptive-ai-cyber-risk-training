# Security Policy

This repository is an educational and defensive research prototype. It is not intended to support offensive cyber activity.

## Reporting issues

Please report security or safety concerns by opening a GitHub issue with a clear description of the problem and the affected file.

## Safety boundary

Do not contribute or request content that includes:

- Exploit procedures.
- Malware or payload generation.
- Credential theft or phishing operational details.
- Evasion, persistence or unauthorised access guidance.
- Instructions that enable harm against real systems.

Acceptable content includes risk assessment scenarios, control evaluation, residual risk reasoning, training methodology and responsible AI documentation.
