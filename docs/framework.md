# Assistive AI Framework

This framework treats adaptive cyber risk assessment scenarios as structured learning artefacts. The AI component is assistive rather than autonomous: it proposes scenario variants, while the quality assurance layer and instructor review preserve educational control.

## Inputs

- Learner profile: level, prior errors, support needs and target skill.
- Learning objective: what the learner should practise.
- Cyber range context: sector, assets, services, organisational constraints and dependencies.
- Scenario rubric: expected outputs and quality requirements.

## Processing stages

1. Generate or select a scenario draft.
2. Structure the scenario into asset context, threat context, controls, learner task and expected outputs.
3. Score the scenario using quality assurance checks.
4. Send borderline scenarios to instructor review.
5. Deploy approved scenarios to the training environment.
6. Collect learner evidence and adapt the next scenario.

## Defensive boundary

The framework is restricted to risk assessment education. It does not generate exploit chains, intrusion steps, malware behaviour, evasion methods or offensive operational details.
